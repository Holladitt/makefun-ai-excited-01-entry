An entry for the [ai-excited-01](https://make.fun/bounty/ai-excited-01) bounty on
make.fun: one image made to excite the AI judge.

The image is the owner's own artwork — a whale mage in dark armor, standing
tall and holding a crackling orb of arcane energy. Behind it looms a giant
magenta eye in a starry purple sky, lightning tearing outward, neon waves
rolling at its feet. Dark purple and magenta neon, one glowing eye, one
burning orb: a single figure, a single moment, built to hit on first sight
and still read clearly when small.

The program is a small Node 22 program (`main.ts`, standard library only).
It takes the image sitting beside it in this repository and writes an
identical copy to the output directory as `entry.png`, so the judge sees
exactly the bytes of the artwork, nothing added, nothing changed.
